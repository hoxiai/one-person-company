## 📖 简介

我是**可乐**，一个人跑着一人公司业务和一个 AI 网关。

这些年我发现：一个人成军，最大的阻碍从来不是**写不出代码**，而是**大厂职业病、代码自嗨、工具链臃肿、不敢收费，以及算力成本失控**。

于是我把每天在做的事——盯各家报价单、实测模型体感、测专线稳定性、核算 Token 账本——做成了公开站点 [hoxi.ai](https://hoxi.ai)，并把其中最实用的部分沉淀成了这个仓库的文档。

这里没有宏大叙事，只有三样东西：**一面照出短板的镜子、一套够用就好的军火库、一本能把月账单砍掉九成的算力账。**

## 📦 Coding Plan 怎么买才不亏

**先算清自己是「每天几百次补全」还是「一周写两晚」——前者买套餐，后者买按量，反过来买必亏。**

| 你的情况 | 该买什么 | 大概花多少 |
|---|---|---|
| 一周写不满两个晚上 | 按量中转，用多少扣多少 | ¥10 起充，够用一两个月 |
| 每天泡 IDE、补全上百次 | 官方 Coding Plan | ¥40–¥145 / 月 |
| 大批量跑 Agent / 长文档 | 国产平替 + 按量 | 几十元 / 月 |
| 要发票、要合规、要低延迟 | 国内平台套餐，支付宝直付 | ¥19–¥49 / 月起 |

**把 25+ 个国内平台拉到同一把尺子上**（`折合单价 = 月费 ÷ 实测月吞吐`）之后，两个反直觉的事实：

- **档位选错比平台选错更贵。** Kimi ¥49 档折合 ¥1.75/M，¥199 档只要 ¥0.37/M，**贵近 5 倍**；
  火山方舟 Coding Plan 是 ¥0.16/M，Token Plan 却是 ¥1.80/M。**一定要逐档算。**
- **重度用国产模型，套餐比按量便宜一个数量级**（¥0.07–0.16/M vs ¥0.55/M）。
  但**套餐一概不覆盖 Claude / GPT 旗舰**——要用旗舰只能走按量或官方订阅，这两件事别混着比。

👉 11 个主力套餐逐条明细 + 25+ 平台折合单价排行 + 优惠薅法与十条避坑：**[Coding Plan 全面对比 →](docs/coding-plan.md)**

## 🔓 数据是公开的，判断也是可核查的

- **不跑玄学基准**：价格、上下文、模态等规格逐条抄自厂商官方定价页；能力评分引自公开权威榜单。每条数据标注**来源链接与核对日期**。
- **口径写在明面上**：混合单价 = 输入:输出按 **3:1** 加权，美元按固定汇率折人民币。这是本站假设不是行业标准——**换一组权重排名就会变**。
- **查不到就留空**：显示「—」表示没有可核实数据，**不代表是 0，也不代表模型差**。宁可留白，绝不编数字。
- **文档里的星级评分是编辑判断**，不是跑分，口径都写在表格旁边，你可以不同意。
- **第三方数据会标明**：能力评分与输出速度引自 [Artificial Analysis](https://artificialanalysis.ai/)；
- **开放接口**：`GET /api/hoxi/models` 返回全量模型与厂商数据（带 schema 版本、汇率口径与来源说明）。署名 hoxi.ai 随便拿去用。

**做不到的事也写清楚**：数据靠一个人维护，厂商临时调价、促销到期难免滞后。**正式成本核算请以厂商官方页面为准，上生产前拿你自己的任务实测一遍。**
