## 三、🌐 国外套餐明细

### Cursor Pro — $20 / 月（≈¥145）

- **额度**：每月 500 次 Fast Requests，超额后**无限次慢速排队**；支持多文件 Composer
- **模型**：覆盖 Claude / GPT 旗舰系列（以官方页为准，会随厂商更新）
- **值在哪**：当前最主流的 AI 编程 IDE，多文件跨模块重构第一梯队；超额后可挂自己的 API Key 续杯
- **⚠️ 避坑**：需绑海外信用卡；500 次高速额度**重度开发约 10–15 天就见底**，之后高峰期排队体感明显

### Claude Pro — $20 / 月（≈¥145）

- **额度**：每 5 小时约 45 条消息（随全网负载浮动），支持 Thinking 深度思考
- **值在哪**：Artifacts 实时渲染前端组件；Projects 可把整个代码库当背景上下文
- **⚠️ 避坑**：**官方风控极严**，国内 IP 或非纯净代理节点极易封号拒付。真要用，账号和支付环境都得干净；5 小时窗口在连续 Debug 时很容易撞墙

### GitHub Copilot — $10 / 月（年付 $100，≈¥72/月）

- **额度**：**无限次**行内智能补全，Chat 可自由切换底层模型
- **值在哪**：补全延迟极低；**国内基本可直连**，是门槛最低的一档
- **🎓 免费**：学生、教师、开源项目维护者可申请**完全免费**——符合条件的别花这钱
- **⚠️ 避坑**：跨多文件的大型架构生成，仍略逊独立 Cursor

### ChatGPT Plus — $20 / 月

- **额度**：GPT-4o 每 3 小时 80 条；推理模型另有周限额
- **值在哪**：多模态最全，Canvas 改小模块代码顺手
- **⚠️ 避坑**：需海外支付方式，对代理 IP 环境敏感

### Windsurf Pro — $15 / 月（≈¥108）

- **额度**：每月 500 次 Fast Prompts，Cascade 多文件协同 Flow
- **值在哪**：比 Cursor 便宜 $5，Agent 协同流上下文连贯度高
- **⚠️ 避坑**：插件生态仍在追赶 VS Code / Cursor

### Google One AI Premium — $19.99 / 月（**首月免费**）

- **额度**：1M 超大上下文，另送 2TB 云盘
- **值在哪**：一次性吞整个大型代码库 / 长视频；「AI + 网盘」二合一算下来不亏

## 六、怎么算「值不值」：两种口径，别混着看

**别看月费，看折合单价。** 但折合单价有两种算法，混着看会得出完全相反的结论：

| 口径 | 公式 | 用来干嘛 |
|---|---|---|
| **A · 标称额度** | 月费 ÷ 厂商写明的 Token 额度 | 保守估算，看「最坏情况值不值」 |
| **B · 实测吞吐** | 月费 ÷ 实际能跑出的 Token 量 | 贴近真实体验，多数人关心的 |

**为什么 B 常常远大于 A**：多数 Coding Plan / Token Plan 实际是靠**请求数与限流**来控制成本，
而不是严格按 token 结算。所以真实跑出来的吞吐，往往**显著高于**宣传页写的标称额度。

| 方案 | 月费 | 口径 A（标称） | 口径 B（实测） |
|---|---:|---:|---:|
| 阿里云百炼（低档 Token 包） | ¥49 | 1000 万 token → **¥4.90 / M** | — |
| 火山方舟 Coding Plan Lite | ¥40 | 未公开 | 约 2.5 亿 token → **¥0.16 / M** |
| MiniMax Plus | ¥49 | 未公开 | 约 6 亿 token → **¥0.07 / M** |
| 按量专线 · 平替档 | 按需 | — | **¥0.55 / M** |
| 按量专线 · 旗舰档 | 按需 | — | **¥2.80 / M** |

### 所以到底买哪个

**盈亏平衡点**：以 ¥40 的方舟 Coding Plan Lite 为例，
同样 ¥40 走按量平替档（¥0.55/M）只能买约 **7,200 万 token**，而套餐实测能跑约 2.5 亿。
👉 **月用量超过约 7,000 万 token，套餐就明显更划算。**

但有一个**必须说清楚的前提**：

> 🔴 **国内套餐便宜的是国产模型**（GLM / Doubao / MiniMax / Kimi / DeepSeek 等）。
> **要用 Claude / GPT 旗舰，这些套餐一概不覆盖**——只能走按量中转或官方订阅。
> 拿国产套餐的 ¥0.07/M 去比中转旗舰的 ¥2.80/M，比的不是同一个东西。

| 你的情况 | 结论 |
|---|---|
| 重度用国产模型（月 > 7000 万 token） | **买套餐**，比按量便宜一个数量级 |
| 轻度、用量波动大 | **按量**——套餐有月费底线，额度还月底作废 |
| 必须用 Claude / GPT 旗舰 | 套餐帮不上，走[按量中转](gateways.md)或官方订阅 |
| 要发票 / 合规 / 对公 | 国内平台套餐，支付宝直付可开票 |

**订阅制怎么算？** Cursor Pro ¥145 ÷ 500 次高速 = **¥0.29 一次**，超额还能无限慢速。
它卖的是 IDE 体验和「不用算账」，用 token 单价去比它，本身就比错了对象。

## 八、十条避坑（都是交过学费的）

1. **别用促销价做全年预算**——限时折扣到期普遍回涨一到两倍。
2. **别在试水期年付**——年付省的钱，抵不过用两个月就不用了的损失。
3. **高速配额 ≠ 无限**——Cursor / Windsurf 的 500 次，重度用 10–15 天就见底。
4. **Claude 官方风控极严**——国内 IP、非纯净节点、共享账号，都是封号高发因素。
5. **Token 包会过期**——月底作废，别买超过自己用量的档位。
6. **同平台的档位差价能到 5 倍**——Kimi ¥49 档折合 ¥1.75/M，¥199 档只要 ¥0.37/M；
   火山方舟的 Coding Plan 是 ¥0.16/M，Token Plan 却是 ¥1.80/M。**逐档算，别只看月费高低。**
7. **国内包不含闭源海外模型**——需要 Claude / GPT 的，别指望国产 Token 包。
8. **警惕几分钱的中转**——掺水、降智、偷换小模型是常态，省下的钱会用返工时间还回来。验真方法见 [中转专线实测与配置](gateways.md) 的「如何验真」一节。
9. **单价低 ≠ 总账单低**——不同厂商分词器不同，同段中文切出的 token 数可能差三成。
10. **同时开三四个订阅是最贵的错**——先砍到一个主力 + 一个按量兜底，账单立刻降一半。

## 九、数据口径与免责

### 数据来源

- **第一至四节**（11 个主力套餐）：价格、额度、支付方式、网络要求逐条核对自各厂商**官方定价页**，核对日期见页首。
- **第五节**（25+ 平台折合单价排行）：月费与购买状态取自各平台官方页；「实测月吞吐」汇总自公开社区实测数据，**折合单价一列为本站按 `月费 ÷ 实测吞吐` 自行换算**。
- 美元按 1 USD = 7.2 CNY 折算，与本站榜单口径一致。

### 局限

- **实测吞吐存在个体差异**——它取决于你的上下文长度、并发方式与使用时段，别把它当成合同承诺。
- **星级评分是编辑判断，不是跑分**——口径写在第二节表格上方，你可以不同意。
- 显示「—」表示**没查到可核实数据**，不代表是 0，也不代表差。
- 厂商调价、促销到期、套餐改版随时发生，**做正式成本核算前请以厂商官方页面为准**。
