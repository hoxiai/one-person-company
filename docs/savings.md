## 🌳 降本决策树：别一上来就开月费

### 规则 1 · 轻量 / 试水期 → 直接用高质中转

月消耗低于 **1000 万 Token** 时，千万别开动辄 $20–$40 的按月订阅。
靠谱中转按量计费，用多少扣多少，**几十块钱能写一两个月**。

### 规则 2 · 重度高频编码 → 优先选 Coding Plan

每天泡在 IDE 里几百次补全、频繁多文件重构，
直接上 Cursor / Copilot / 方舟等官方套餐，高速配额折算下来单价极划算。
👉 怎么挑见 [Coding Plan 对比](coding-plan.md)

### 规则 3 · 复杂长文本 / 思考模式 → 首选国产平替

DeepSeek、Qwen Coder 这类国产第一梯队，编程表现已逼近顶级旗舰，
价格只有旗舰的 **1/10 到 1/20**，大批量任务直接平替。

## 🎯 站长实操黄金搭配（70 / 20 / 10）

大部分人账单爆炸，不是因为用得多，而是**从头到尾只用最贵的那一个**。

| 占比 | 干什么 | 用哪档 | 参考单价 |
|---:|---|---|---|
| **70%** | 日常刷基础代码、样板文件、写测试、补注释 | 极速便宜档（Flash 系） | ≈ ¥0.7 / M |
| **20%** | 攻坚重构、跨文件改动、疑难 Debug | 旗舰思考模型，按量走专线 | ≈ ¥2.8 / M |
| **10%** | 交叉验证，避免一条道走到黑 | 换一家旗舰复核 | 按量 |

> **算力别贪贵，主力控制在百元内。**
> 一个实操细节：把「切换模型」做成肌肉记忆——写样板代码时手动降档，
> 比任何省钱技巧都管用，因为它省掉的是**你根本不需要的那部分推理**。

## 🧰 六条立刻能省钱的技巧

### 1. 把稳定不变的内容放进缓存

多数厂商的**缓存命中价只有输入价的 1/10 左右**。系统提示、代码库、长文档这些每次都要带上的内容，放进缓存后重复调用成本大幅下降。
⚠️ 各家计费方式不同：有的收缓存写入费，有的按缓存存储时长收费——先看清再用。

### 2. 按难度分流，不要一个模型跑到底

把分类、抽取、格式化这类简单任务交给便宜档，只把真正需要推理的步骤交给旗舰。
**多数 Agent 链路里，需要顶级能力的步骤不到两成。**

### 3. 调低推理档位

同一个模型的 max 与 medium 档**单价相同**，但输出的思考 token 数差很多，首字延迟也差出几十秒。
不需要深度推理的任务把档位调下来，**省钱又变快**。

### 4. 用批量接口和空闲时段

多家厂商的批量调用是**五折**，部分厂商还有空闲时段半价。
不赶时间的离线任务放进批量或错峰跑，**成本直接减半**。

### 5. 当心阶梯价和促销价

不少模型按输入长度分档，超过阈值单价会**跳一到两倍**；
也有模型现在的低价是限时促销，到期会翻倍。
**做长期成本估算时，一律按到期后的价格算。**

### 6. 别只看单价，要看同一段文本切出多少 token

不同厂商的分词器不同，同样一段中文切出的 token 数**可能差三成**。
单价低不等于总花费低——最可靠的办法是拿自己的真实语料各跑一遍再比总账单。

## 📒 算力账本模板（直接抄）

一人公司最怕的不是花钱，是**不知道钱花在哪**。每月填一次，五分钟：

| 项目 | 本月花费 | 占比 | 能砍吗 |
|---|---:|---:|---|
| 日常编码（便宜档） | ¥ | % | 降档 / 缩上下文 |
| 攻坚重构（旗舰档） | ¥ | % | 只在关键处用 |
| Agent / 批量任务 | ¥ | % | 走批量五折 / 错峰 |
| 订阅费（闲置的那些） | ¥ | % | **优先砍这项** |
| 合计 | ¥ | 100% | |

三条自检：

1. **订阅费占比超过 40%** → 大概率买多了，砍到一个主力 + 一个按量兜底。
2. **旗舰档占比超过 30%** → 分流没做好，回去看 70/20/10。
3. **总额连续两月上涨但产出没变** → 上下文在膨胀，检查是不是每次都把整个仓库塞进去了。
