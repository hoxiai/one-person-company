## 🧱 一条最小可行技术栈（照抄就能跑）

一个人做产品，技术栈越薄越好。这是我实际在用的：

```
前端 + 后端  →  Nuxt / Next（一个框架吃两头，别拆前后端仓库）
样式        →  Tailwind CSS（不写自定义 CSS 体系）
数据库      →  Supabase / SQLite（先别上分布式）
部署        →  Vercel / Zeabur（Git push 即上线）
CDN + 域名  →  Cloudflare（免费档够用很久）
收款        →  Lemon Squeezy（省税务）/ Stripe（费率低）
AI 算力     →  按量中转专线（见 gateways.md）
```

**月成本可以压到几十元**，从零到上线通常几小时。
真正的瓶颈从来不是技术栈——是**有没有人愿意为它付钱**。
